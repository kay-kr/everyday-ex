## 고칠 때

- 루틴·주차·심박 구간·준비물 → `_dashboard/plandata.js`
- 동작 설명 → `_dashboard/moves.js` (용어 툴팁에도 자동 등록된다)
- 그 밖의 용어 툴팁 → `_dashboard/terms.js`
- 페이지 추가 → `_dashboard/page.html` 복사 후 `_dashboard/pages.js` 에 한 줄
- `dashboard.css` · `dashboard.js` 는 건드리지 않는다

### plandata.js 의 두 갈래

| 키 | 무엇 | 날짜 |
|---|---|---|
| `home.weeks[]` | 집 근력 루틴 3주치. 한 주 안에서는 7일 내내 같다 | `start` 부터 21일 |
| `field[]` | 운동장 6세션 (`f1a` `f1b` `f2a` …) | 없음 — 슬롯만 있다 |

`start` 하나만 바꾸면 21일 전체가 따라 움직인다. 다음 3주를 시작할 때 여기만 고친다.

### 블록의 세 필드

| 필드 | 무엇 | 화면 |
|---|---|---|
| `items` | 하나 끝내면 하나 지우는 실제 수행 항목 | 체크박스가 붙는다 |
| `notes` | 세트 수·속도·자세 유의사항 같은 설명 | 체크박스 없이 회색 줄 |
| `rest` | 그 블록에서 어떻게 쉬는지 | "쉬는 법" 상자. 모든 블록에 하나씩 |

운동장 세션에는 `after` 가 하나 더 있다 — 집에 와서 그날의 집 루틴까지 해야 하루가 채워진다는 줄이다. 바닥에 눕는 동작(클램쉘 · 글루트 브릿지 · 사이드 라잉 힙 앱덕션 · 데드버그 · 폼롤링)은 운동장에 누울 자리가 없어(D9) 전부 집 루틴의 ④·⑤ 칸에 들어가 있다.

### 기록 저장 구조

```
sessions : { "2026-09-21": {done, steps, nrsPre, nrsPost, nrsAm, note} }   // 날짜 — 집 루틴과 무릎
field    : { "f1a": {done, at, steps, rpe, km, hr, note} }                 // 슬롯 — 운동장, at 이 나간 날짜
weights  : { "2026-09-21": 73.5 }
tests    : { t1, t2, t3, t4, at }
```

개편(9/21) 전에 적어 둔 9/14~9/18 기록은 지우지 않았다. 체중·통증 차트는 계획이 아니라 "기록이 있는 모든 날짜"를 그리므로 그 값들도 계속 보인다.

## 강도를 올리는 규칙

푸시업은 횟수가 아니라 **손 짚는 높이**로, 철봉은 **매달리는 시간**으로 올린다 (D11). 6단계 사다리가 `home.ladders` 에 있고, 3주 동안 움직이는 것은 1단계 → 2단계 → 3단계 두 칸뿐이다. 3주 뒤에도 칸과 시간은 그대로 두고 사다리만 한 칸 올린다 (D12) — 매일 하는 운동의 강도를 크게 올리면 매일 할 수 없게 되기 때문이다.

세션 시간은 적는 것이 아니라 블록 `min` 의 합으로 계산된다 (`DB_FIELD_MIN` · `DB_HOME_MIN`).

심박 구간은 1973년생 · 만 53세(HRmax 171) 기준이다. 해가 바뀌어 나이가 오르면 `plandata.js` 의 `profile.age` 와 `profile.hrmax`(208 − 0.7 × 나이), `zones[].bpm` 을 같이 고친다.
